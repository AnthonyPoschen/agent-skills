# v2026.8.14 - 2026-08-14

## Changed

- `implement-tickets` now verifies and publishes each completed worker's draft
  review immediately while sibling workers continue, shortening the path from
  implementation to human review.
- Review feedback now requires a trusted source before it can launch follow-up
  implementation. The supervisor accepts native CI failures, recognized CI or
  scanner findings, and non-agent feedback from the authenticated tracker
  account.
- Third-party feedback becomes actionable only when the authenticated account
  adds a clearly positive reaction to the exact comment or explicitly endorses
  it in context. Comment-based endorsements preserve both the original feedback
  and the human authorization in the worker prompt.

## Fixed

- Unendorsed third-party review comments can no longer cause arbitrary code
  changes.
- Agent-written `AI-generated:` comments remain excluded even when posted
  through the authenticated account.
- Generic or ambiguous reactions and approvals no longer authorize unrelated,
  earlier, or later review feedback.
