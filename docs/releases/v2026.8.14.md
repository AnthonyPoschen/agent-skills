# v2026.8.14 - 2026-08-14

## Changed

- OpenCode workers now use the repository's reviewed `opencode.json` policy
  instead of an injected configuration that could override project settings.
  The bundled template remains deny-by-default and documents the host-level
  isolation needed for untrusted repositories.
- OpenCode runs now preserve the manager's Git identity, accept compatible
  commit subjects from conventional work-item titles when handoff output is
  incomplete, and retry one unambiguous verification failure before requiring
  human attention.
- GitLab orchestration now normalizes open issue state, discovers explicit
  `Blocked by` references, acknowledges actionable notes, and replies in the
  originating discussion without giving workers tracker credentials.
- `implement-tickets` now verifies and publishes each completed worker's draft
  review immediately while sibling workers continue, shortening the path from
  implementation to human review.
- Review feedback now requires a trusted source before it can launch follow-up
  implementation. The supervisor accepts native CI failures, recognized CI or
  scanner findings, and non-agent feedback from the authenticated tracker
  account.
- Third-party feedback becomes actionable only when the authenticated account
  adds a clearly positive reaction to the exact comment or explicitly endorses
  it in context. Comment-based endorsements preserve both the original feedback
  and the human authorization in the worker prompt.

## Fixed

- OpenCode supervisor recovery now processes operator inbox requests before
  launching more work, avoids project-policy replacement, and keeps test event
  logs out of the source tree.
- GitLab API reads no longer depend on unsupported `glab api --jq` behavior,
  and cloned worker repositories inherit the manager checkout's Git identity.
- Unendorsed third-party review comments can no longer cause arbitrary code
  changes.
- Agent-written `AI-generated:` comments remain excluded even when posted
  through the authenticated account.
- Generic or ambiguous reactions and approvals no longer authorize unrelated,
  earlier, or later review feedback.
