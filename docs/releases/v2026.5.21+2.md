# v2026.5.21+2 - 2026-05-21

## Added

- Added the `makefile` skill for creating and reviewing Makefiles with required
  variable validation before target commands run.
- Added a reusable `check_defined` helper pattern for Make targets that accept
  user-provided variables such as usernames, tokens, branches, paths,
  namespaces, and environments.
- Added guidance for clear missing-variable error descriptions, secret-safe
  validation, `.PHONY` targets, quoted Make variable expansion, and avoiding
  collisions with common environment variables such as `PATH`.
