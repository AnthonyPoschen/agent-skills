# v2026.8.25 - 2026-08-25

## Added

- Added `context-management` for focused investigation, compact handoffs, and
  bounded delegation.
- Added `experience-first` to keep product, API, and internal interface choices
  focused on the consumer's real workflow.
- Added `encode-lessons` to turn repeated mistakes and costly failure modes into
  the smallest durable guard.
- Added `act-within-scope` so agents gather material questions early, then make
  ordinary reversible decisions without unnecessary pauses.
- Added technical-writing and skill-evaluation guidance for clearer
  documentation and evidence-based skill changes.
- Added file-organization guidance, including Go layout conventions, to make
  source paths and boundaries easier to discover.

## Changed

- Strengthened coding guidance around consumer-driven boundaries, direct code
  versus abstractions, first-principles refactoring, and subtraction before new
  structure.
- Made direct outcome proof and real local dependencies the preferred evidence
  for dynamic behavior. Automated tests now focus on stable, meaningful
  contracts rather than incidental implementation details.
- Updated commit guidance to use concise descriptive subjects instead of
  Conventional Commit prefixes. It also explains when separate commits make
  review, rollback, and cherry-picking easier.
- Combined changelog and versioning guidance into the `release` skill. Releases
  follow repository conventions and use CalVer only when no convention exists.
- Improved `implement-tickets` project setup and Jira work-source guidance.
- Added isolated Omarchy source-development guidance with disposable VM testing.

## Notes

- This release adds guidance and skills. It does not require a consumer-facing
  migration.
