# v2026.8.17 - 2026-08-17

## Added

- Added a Grok harness for `implement-tickets`, including isolated native
  subagents, review monitors, scheduled polling, and a least-privilege worker
  agent template.
- Added shared project-contract options for related repositories, reserved
  numbered-file sequences, and forbidden commit patterns so parallel work can
  coordinate safely.

## Changed

- Managers now treat Git-verified merged reviews as dependency completion even
  when a tracker item remains open, then close the leftover item as
  post-integration housekeeping.
- Authorized review questions now receive an `AI-generated:` reply on the
  originating ticket or review thread during the same polling cycle.
- OpenCode workers retain session context for follow-up requests and surface
  actionable permission-prompt failures.

## Fixed

- Supervisor feedback replies now work for both GitHub and GitLab reviews.
- Checkpoint publication rejects configured forbidden added lines before
  committing worker changes and reserves shared sequence numbers across active
  and related checkouts.

- `npm run validate`
