# v2026.5.20+2 - 2026-05-20

## Added

- Added the `changelog` skill for generating user-facing changelogs, release
  notes, GitHub release text, upgrade notes, and release summaries from
  committed changes.
- Added guidance for adaptive changelog conventions, including GitHub Releases,
  per-release files under `docs/releases/`, and concise `CHANGELOG.md` indexes.

## Changed

- Updated the `calver-release` skill to check for existing changelog or
  release-note conventions before tagging.
- Releases now require changelog/release-note updates to be completed and
  committed before tagging when a repo already has changelog evidence, unless
  the user explicitly skips that step.

- `npm run validate`
