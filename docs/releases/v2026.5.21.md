# v2026.5.21 - 2026-05-21

## Added

- Added assertion-focused coding guidance covering invariant checks,
  debug-vs-production assertion choices, and fail-fast contracts.
- Added dedicated assertion routing from the `coding` skill so agents can load
  assertion guidance only when a task needs it.
- Added the `flux-ghcr-image-automation` skill for designing and debugging
  GitHub Actions to GHCR to Flux image automation loops.
- Added Flux image automation references for orderable GHCR tags, Flux
  `ImageRepository`, `ImagePolicy`, `ImageUpdateAutomation`, setter comments,
  namespace checks, and rollout diagnostics.

## Changed

- Updated the `calver-release` skill to use Go-module-safe CalVer tags in the
  `v0.YYYYMMDD.N` format when a repository has `go.mod`.
- Go module releases now avoid date-based major versions such as
  `v2026.5.21`, which can trigger Go's major-version path rules and resolve as
  `+incompatible`.
- Documented the release process requirement that changelog or release-note
  updates must be committed before tagging when the repository already has a
  release-note convention.
