# Writing

Two references cover prose for people. Load the ones the text needs.

## Routing

- Every reply or piece of prose for a person: read
  [asd-ste100](./references/asd-ste100.md). It controls each sentence.
- Documentation, READMEs, tutorials, how-to guides, RFCs, architecture notes,
  PR descriptions, release notes, or commit messages: also read
  [technical-writing](./references/technical-writing.md). It selects the
  document type and structure.
